## 目錄規範

文檔的目錄與文件命名，需與組件的命名對應。子目錄可自由發揮，但一般可參考以下規則：

- `index.md` 組件主文件
- `detail/` 組件詳情文件。一般在主文件內容過大時，可將內容碎片放置在該目錄中，主文件只需引用即可。
- `examples/` 組件示例文件。

當創建新的組件文檔時，可複製 `.layui/` 目錄中放置好的文檔模板，並填充對應的內容。

## 書寫規範

文檔採用 `HTML+Markdown+laytpl` 混合編寫。 其中：

- `HTML` 標籤與 `Markdown` 混用時，必須換兩行隔開
- `laytpl` 標籤語法可直接遵循 Layui 中的 laytpl 組件規則
- 若需開啟文檔的右側目錄，可在對應錨點元素上添加 `lay-toc="{}"` 屬性即可，具體可參考其他組件中的內容
